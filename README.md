# EWU Cafeteria Management System

The EWU Cafeteria Management System is a web-based system developed to make cafeteria food ordering and management easier.

The system has three types of users:

- Student: Can browse food, place orders, make payments and check order status.
- Staff: Can view orders and update their status.
- Admin: Can manage food items, categories, students, staff, orders and inventory.

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- SQL
- XAMPP

## Main Features

- User login
- Food menu
- Food ordering
- Payment
- Order management
- Order status tracking
- Student management
- Staff management
- Category and food item management
